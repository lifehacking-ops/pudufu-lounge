# 프드프 라운지 프로토타입

**2026 돈 되는 릴스 라운지** 기획을 화면으로 옮긴 정적 프로토타입. 빌드 도구 없이 파일만 열면 동작한다.

| 파일 | 내용 |
|---|---|
| `lounge-web-prototype.html` | 웹(데스크톱) 버전. 커뮤니티 · 강의 목록 · 강의 상세 3화면. **현재 기준안** |
| `lounge-prototype.html` | 460px 모바일 컬럼 선행 버전. 웹 버전으로 대체됨 |

## 보는 법

```
open lounge-web-prototype.html
```

`file://` 로 열어도 되고, 로컬 서버로 띄워도 된다.

```
python3 -m http.server 8000
```

## 기획 출처

노션 `Skool.com 에서 프드프로 가져올만한 자산`. 커뮤니티 본질 정의부터 P1 여덟 항목까지 담겨 있다.
각 HTML 파일 하단의 스펙 시트에 P1 항목과 화면 요소의 대응표가 들어 있다.

핵심은 **게시판을 필터로 대체**하는 것이다. 프드프 현재 라운지 좌측 사이드바의 게시판
(자유 커뮤니티 / 릴스 피드백 / 올인원 AI 피드백)을 없애고, 카테고리 · 보기 · 회차 · 정렬을
동시에 걸 수 있는 필터 칩으로 옮겼다. 화면 전환이 사라지고 조합이 생긴다.

## 디자인 시스템

`aistudy`(AI눈높이 LMS) 저장소를 그대로 참조한다.

- 토큰: `app/globals.css` 의 `@theme` 블록. 무채색 기조, 강조색 없음, 의미색은 late/danger 둘뿐
- 규칙: `docs/DESIGN.md`. 카드 · 히어로 · 버튼 · 인풋 · 배지 · 8주 리본 조합
- UI 에 이모지를 쓰지 않는다. 한글은 Pretendard, 숫자는 Space Grotesk

의도적으로 벗어난 세 가지(460px 컬럼 → 웹 그리드 / 검정 반전 면 미사용 / 필터 칩을 세그먼트
트랙 대신 개별 알약)는 각 파일 하단 스펙 시트에 이유와 함께 적어 두었다.

## 주의

Pretendard 는 jsdelivr CDN 에서 받는다. CSP 로 외부 스타일시트를 막는 환경에서는
`globals.css` 에 적힌 폴백(Apple SD Gothic Neo)으로 떨어진다. 로컬이나 자체 호스팅에서는 정상이다.

피드 · 검색 · 리더보드의 이름과 수치는 전부 예시 데이터다.
